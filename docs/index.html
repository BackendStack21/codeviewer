Codeviewer is a fast, read-only code viewer with a real terminal built in. Point your favourite CLI agent at a project and watch every file it touches update live, with git telling you exactly what changed.

Built for watching code change

Everything an IDE shows you, nothing that lets anything slip in by accident: Codeviewer never edits a file.

A real terminal, built in

A native PTY and a from-scratch xterm-grade emulator: truecolor, mouse, alternate screen, bracketed paste and crisp box drawing. Run Claude Code, Codex, aider, vim or htop right next to the code.

Live while agents work

Files reload in place as they change on disk. Changed lines flash, the explorer marks them, and nothing you are reading jumps.

Git, read-only

Status letters in the explorer, gutter markers against HEAD with a peek at the old lines, inline blame, branch, ahead/behind and merge state. It never writes to your repository.

Fast at any size

Virtualized everything: 100k-line files open instantly, quick-open searches 200k paths as you type, and the terminal streams megabytes per second.

Locked down

The window can only reach its own local server. Header-token auth, DNS-rebinding and CSRF guards, and git hardened against hostile repositories. Reviewed adversarially.

Native and small

A 40 MB Mac app on the system WebKit, with real menus, window tabs and a folder picker. Built with Bun and TypeScript and zero third-party dependencies.

See what HEAD had

Click any gutter marker to peek at the lines as they were in the last commit. Inline blame follows your cursor; the status bar shows the branch, how far ahead or behind you are, and every changed file is one ⌘⇧G away.

  • Explorer letters: M modified, A added, U untracked, D deleted, C conflict
  • Live as you or an agent edit, stage, commit or switch branch
  • Safe on untrusted repositories: no hooks, filters or drivers ever run

A shell in a window deserves care

Codeviewer serves a real terminal, so it was designed and then attacked by reviewers looking for a way in. Every confirmed finding was fixed and pinned with a test.

Only its own server

The Mac window blocks every request except its own local port. External links open in your browser, never inside the app.

No ambient credentials

A random 256-bit token lives in the URL fragment and a request header. No cookies, no token in process lists, Host and Origin checked on every request.

Hostile repos are fine

Git runs without filters, textconv, signature checks, fsmonitor or submodules, and never writes your index. Read the design and review notes.

Verify before you run it

Every release is built by GitHub Actions from a tagged commit, on a clean runner. Two independent checks prove the file you have is that build.

  1. Download the app and the checksum list

    curl -LO https://github.com/BackendStack21/codeviewer/releases/download/v1.0.0/Codeviewer-1.0.0-macos-arm64.dmg
curl -LO https://github.com/BackendStack21/codeviewer/releases/download/v1.0.0/SHA256SUMS

    Intel Mac: use Codeviewer-1.0.0-macos-x64.dmg.

  2. Check the SHA-256

    shasum -a 256 -c SHA256SUMS --ignore-missing

    Expect Codeviewer-1.0.0-macos-arm64.dmg: OK. It must also match the hash in the table above.

  3. Check where it was built

    # GitHub CLI: https://cli.github.com
gh attestation verify Codeviewer-1.0.0-macos-arm64.dmg --repo BackendStack21/codeviewer

    This checks a Sigstore-signed provenance statement logged in a public transparency log. It proves the file came out of this repository's release workflow, at a specific commit. It does not depend on this website.

  4. Install

    Open the DMG and drag Codeviewer to Applications. The app is not notarized by Apple, so the first launch needs right-click → Open, or:

    xattr -dr com.apple.quarantine /Applications/Codeviewer.app

  1. Download the package and the checksum list

    curl -LO https://github.com/BackendStack21/codeviewer/releases/download/v1.0.0/codeviewer-1.0.0-linux-x64.tar.gz
curl -LO https://github.com/BackendStack21/codeviewer/releases/download/v1.0.0/SHA256SUMS

    ARM64: use codeviewer-1.0.0-linux-arm64.tar.gz.

  2. Check the SHA-256

    sha256sum -c SHA256SUMS --ignore-missing

    Expect codeviewer-1.0.0-linux-x64.tar.gz: OK. It must also match the hash in the table above.

  3. Check where it was built

    gh attestation verify codeviewer-1.0.0-linux-x64.tar.gz --repo BackendStack21/codeviewer

    Proves the file came out of this repository's release workflow at a specific commit, independently of this website.

  4. Install

    tar -xzf codeviewer-1.0.0-linux-x64.tar.gz
./codeviewer/install.sh

    Adds codeviewer to ~/.local/bin and a desktop entry. The bundled browser is ungoogled-chromium, itself pinned by SHA-256 in the repository.

Or build it yourself

You need Bun 1.3.5 or newer (and Xcode command line tools for the Mac app). There are no dependencies to install.

git clone https://github.com/BackendStack21/codeviewer.git
cd codeviewer && git checkout v1.0.0
bun run test
bun run build:local
